# Security policy

## Scope

This policy covers this Leaf Essentials fork, including its behavior pack, build and packaging tools, and the add-ons distributed through this repository's Releases. Include the version or commit you tested. Older Azalea repositories and packages from other distributors are outside this fork's release process.

## Report a vulnerability privately

Use this repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue or post sensitive details in a public discussion. If you cannot use private reporting, ask the maintainer for an alternate private channel without including vulnerability details.

Include the affected version, impact, relevant configuration, and the minimum information needed to diagnose the issue. Remove tokens, account identifiers, and private world data from logs and attachments. Use a disposable local world for verification rather than a live Realm or a server you do not own.

## Triage and disclosure

The maintainer will confirm scope and impact, determine affected versions, and verify a fix before publishing an advisory when warranted. Do not assume an automated finding is a confirmed vulnerability or that a development build is ready for public use. Release notes will identify fixes and affected versions when confirmed.
